# 42_Prague

Solutions to the C Piscine and core curriculum projects at 42 Prague.

## Structure

- **Shell00 / Shell01** - Unix basics: permissions, git, find/grep, text
  processing pipelines
- **C00 - C13** - the C piscine, from first `write`-based print functions
  through recursion, string/memory manipulation, and algorithms, up to
  function pointers, linked lists, and binary trees
- **Rush00 / Rush01 / Rush02** - team projects built under time pressure:
  an ASCII pattern generator, a 4x4 skyscraper logic puzzle solver, and a
  number-to-English-words converter with a pluggable dictionary
- **BSQ** - piscine's final project: find and mark the largest square of
  free cells on a map, avoiding obstacles
- **Get_next_line** - reads a text file one line at a time, independent of
  buffer size
- **Ft_printf** - a from-scratch reimplementation of `printf`'s core
  conversions

Each C/Shell/Rush module directory includes the official subject as
`subject.en.pdf`.
